Groq 공용 키 연결

담당자가 서버에 한 번 등록하면 직원은 개인 API 키 없이 계획서와 복지 서비스 AI를 사용할 수 있습니다.

기관 공용 Groq 키 연결을 확인하세요.
담당자 설정 방법 · 키를 다시 볼 수 없을 때
  1. Groq Console API Keys에서 새 키를 만듭니다. 발급 직후 전체 키를 복사하세요. 전체 값이 다시 보이지 않으면 새 키를 발급하고 기존 키를 폐기하면 됩니다.
  2. Vercel 프로젝트의 Settings → Environment Variables에서 이름을 GROQ_API_KEY로 지정하고 키 값을 붙여 넣어 저장합니다. Vercel 공식 안내 ↗
  3. 환경변수 저장 후 프로젝트를 다시 배포합니다. 이 페이지에서 연결 확인을 눌러 인증 상태를 확인하세요.
  4. 직원은 개인 키를 발급하거나 입력할 필요가 없습니다. AI 사용량은 기관 Groq 계정의 한도에 반영됩니다.
  5. 키는 채팅이나 HTML 파일에 넣지 마세요. Vercel 서버 환경변수로만 관리합니다.

자주 묻는 질문

각 도구의 처리 방식을 확인해 주세요.

파일 암호화와 AI 추천 내용은 어디서 처리되나요?＋

문서 파일 암호화는 브라우저 안에서 처리합니다. AI 추천을 누르면 계획서에는 사업명만, 복지 찾기에는 입력한 상황이 기관 Groq 키를 사용하는 서버 함수를 거쳐 Groq로 전송됩니다. 키는 서버 환경변수에 저장하고 브라우저에 보내지 않습니다. 이름, 연락처, 사례기록 등 개인정보는 입력하지 마세요.

사업 계획서는 어디에 저장되나요?＋

작성 중인 내용은 이 브라우저의 저장 공간에 보관됩니다. 다른 기기와 자동 동기화되지 않으니 최종 문서를 내려받아 보관해 주세요. 실명, 연락처 등 민감한 정보는 입력하지 않는 것을 권합니다.

복지 서비스 찾기 결과가 지원 자격을 보장하나요?＋

아니요. 입력 문장의 키워드와 연결되는 제도 예시입니다. 실제 지원 여부는 소득·재산·가구 구성·지역과 신청 시기에 따라 달라지며, 복지로 또는 주민센터에서 확인해야 합니다.

당직·경건회 일정에서 공휴일은 어떻게 처리되나요?＋

선택한 연도에 해당하는 대한민국 공휴일을 달력에 표시하고, 공휴일에는 당직과 경건회를 배정하지 않습니다. 기관 지정 휴무일은 별도로 확인해 주세요.

건강보험료로 중위소득 비율을 정확히 알 수 있나요?＋

정확한 비율을 역산할 수는 없습니다. 2026년 100% 보험료 기준에 비례해 전체 비율을 추정해 보여주지만, 실제 보험료 산정과 사업별 공식 판정표는 다를 수 있습니다. 반드시 해당 사업 담당 기관에 확인해 주세요.

AES-256 암호 ZIP 만들기

다양한 문서를 한꺼번에 모아 강력한 AES-256 암호 ZIP 파일로 압축합니다.

압축할 파일들 선택 (다량 선택 가능)
선택된 파일 없음
AES ZIP은 AES 암호화를 지원하는 압축 프로그램에서 해제할 수 있습니다.

암호 파일 해제 (PDF / AES ZIP)

암호가 설정된 PDF 또는 AES ZIP 파일을 선택하고 암호를 입력합니다.

암호 해제할 파일 선택 (PDF 또는 AES ZIP)
선택된 파일 없음

PDF는 암호 해제된 PDF로 저장되며, AES ZIP은 압축 안의 파일을 개별로 저장합니다.

비밀번호는 문서와 다른 경로로 전달하고 안전하게 보관하세요. 잊어버린 암호는 복구할 수 없습니다. 파일과 암호는 외부 서버로 전송되지 않습니다. 이 도구는 필요한 암호화 라이브러리를 CDN에서 불러올 수 있습니다.
