# 월드비전 송파종합사회복지관 현장 업무 도구

업무 도구 바로가기를 페이지 맨 위의 세로형 분류 목록으로 배치한 웹사이트입니다. 사례관리에는 중위소득 계산기, 복지 서비스 찾기, 초·중·고 학년표, 나이 계산기를 모았습니다. 월드비전 송파종합사회복지관 홈페이지의 흰색 헤더와 주황색 포인트를 참고했습니다.

## 포함된 도구

- **문서 암호화:** 제공된 송파복지관 HTML의 탭과 기능을 유지하며 홈페이지 색상을 반영했습니다. PDF, XLSX, JPG/PNG, AES-256 ZIP 암호화와 지원 형식의 암호 해제를 제공합니다.
- **사업 계획서:** 처음 제공된 예시의 8개 항목(개요, 목적, 목표, 세부진행내용, 참가자명단, 업무분장, 예산, 평가)을 유지합니다. 참고 페이지처럼 개요·목표 → 진행·참가자 → 예산·평가의 3단계로 작성하며, TXT·인쇄/PDF·예산 XLSX로 내려받습니다.
- **사업 계획서 AI 추천:** 사업명만 기관 공용 Groq 키로 보내 목적, 목표, 방법·도구·지표가 각각 있는 평가 2개를 추천합니다. 결과는 확인 후 적용합니다. 키는 서버 환경변수에만 저장됩니다.
- **복지 서비스 추천:** 상황에 맞는 문의 경로, 기관에 물어볼 내용, 다음 단계를 제안합니다. 종합심리검사(풀배터리) 지원 여부는 보장하지 않으며 기관에 별도로 확인하도록 안내합니다.
- **당직 일정 / 경건회 일정:** 각각 별도 도구와 월별 달력, CSV로 만듭니다. 당직은 평일 1명·토요일 2명·일요일 없음, 경건회는 월~목 1명·금요일 파트너십을 반영합니다. 공휴일에는 일정을 배정하지 않습니다.
- **중위소득 계산기:** 2026·2027년 가구원 수별 기준 중위소득 비율표와 월소득 비율을 표시합니다. 건강보험료 3개월 평균은 2026년 100% 보험료 기준에 비례해 전체 비율을 참고 추정합니다. 실제 보험료 산정·사업별 판정표와 다른 계산이므로 자격 판정에 사용하지 않습니다.
- **랜덤 룰렛, 나이 계산기, 연도별 초·중·고 학년표.**

## 기관 공용 Groq 키 설정

1. 담당자가 [Groq Console API Keys](https://console.groq.com/keys)에서 키를 발급합니다. 발급 직후 전체 키를 안전한 장소에 보관하세요. 전체 값이 다시 표시되지 않는 키를 잃어버렸다면 기존 키를 폐기하고 새 키를 발급합니다.
2. Vercel 프로젝트의 **Settings → Environment Variables**에 `GROQ_API_KEY` 이름으로 키를 저장하고 **Production** 환경을 선택합니다. 값은 이 대화나 HTML, 소스 파일에 입력하지 않습니다.
3. 저장한 뒤 프로젝트를 다시 배포합니다. 배포된 페이지 상단에서 **연결 확인**을 눌러 Groq 인증 상태를 확인합니다.
4. 직원은 별도 Node.js 설치나 개인 API 키가 필요하지 않습니다. 배포된 웹 주소를 열면 됩니다. AI 사용량은 기관 Groq 계정 한도에 반영됩니다.

서버 함수는 키를 브라우저로 보내지 않고 Vercel 환경변수에서 읽습니다. 공개 사이트라면 AI 요청을 기관 직원이 아닌 방문자도 보낼 수 있으므로, 직원 전용 서비스는 호스팅 접근 제한을 함께 설정하세요. 이름, 주민등록번호, 연락처, 구체적인 사례기록 등 개인정보·민감정보는 AI에 입력하지 마세요.

Groq는 `openai/gpt-oss-20b`를 사용하며, Groq API는 OpenAI 호환 채팅 완료와 JSON 스키마 응답을 사용합니다. [Groq 빠른 시작](https://console.groq.com/docs/quickstart), [모델 목록](https://console.groq.com/docs/models)을 확인하세요.

## 로컬 실행

개발자가 로컬에서 확인할 때 압축을 풀고 Node.js가 설치된 Windows에서 `start-local.bat`을 더블클릭합니다. Node.js가 없다면 [공식 Node.js LTS 다운로드](https://nodejs.org/en/download/)에서 설치합니다. 공용 Groq 기능을 로컬에서 확인하려면 실행 전에 `GROQ_API_KEY` 환경변수도 설정해야 합니다. 일반 직원은 이 로컬 실행 과정을 거치지 않고 배포된 사이트를 사용합니다.

## 배포와 공휴일 달력

온라인에서 사용하려면 서버 함수가 지원되는 호스팅에 프로젝트 전체를 배포해야 합니다. 일반 정적 호스팅만 사용하면 키 확인과 AI 추천이 작동하지 않습니다. 공휴일은 우선 사이트 API에서 불러오고, 그 경로가 없거나 실패하면 공개 Nager 공휴일 API 두 곳을 차례로 시도합니다. 공휴일 달력을 가져오지 못하면 공휴일이 빠진 일정이 만들어지지 않도록 생성을 막습니다. 실제 근무표 확정 전에는 기관 지정 휴무일과 정부의 최신 공휴일 공고를 확인하세요.

문서 파일은 브라우저에서 처리하며 필요한 라이브러리는 CDN으로 불러옵니다. 사업 계획서 내용은 브라우저 `localStorage`에 저장되므로 공용 PC에서는 사용 후 브라우저 데이터를 정리하세요. 복지 추천은 참고용 AI 초안이며 지원 자격이나 현재 접수 여부를 판정하지 않습니다. 풀배터리 검사가 필요한 경우 검사 종류와 기관이 지원 범위에 들어가는지 복지관·주민센터·지자체에 직접 확인하세요.
